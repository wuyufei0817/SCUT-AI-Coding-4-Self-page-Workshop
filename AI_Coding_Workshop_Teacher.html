巡场

只会遇到这三类问题

A. AI 返回了 Markdown 围栏　→　删掉围栏
B. 页面没有刷新　→　再运行 preview
C. 页面报错　→　让 AI 修，不要手写

33–37 分钟　Part 6

AI 写的代码一定正确吗？

不一定。

点击 Switch Theme —— 没有反应。

不要只问「为什么不行」

给 AI 四样东西

1. 完整代码
2. 发生了什么
3. 你预期什么
4. 报错信息

AI 说已经修复，没有意义。

重新运行并自己验证，才算修复。

37–42 分钟　Part 7

现在你是产品经理

我希望我的主页
还可以做什么？

今天真正学习的是什么

不是 HTML / CSS / JavaScript

Describe → Generate → Run → Inspect → Iterate → Debug → Verify

AI Coding ≠ AI 替你思考

AI 可以写代码、改代码、找 Bug、解释代码。

改变的是「如何写程序」
不是「是否需要思考」
