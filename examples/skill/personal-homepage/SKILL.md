# Personal Homepage Skill

## When to use

当需要创建或优化个人主页时。这是一份教学示例，具体工具的加载方式见 [Skill 说明](../README.md)。

## Goal

让页面更清晰、更专业，同时保留已有内容。

## Guidelines / Workflow

1. 先理解页面用途、用户本次需求和已有内容。
2. 保留已有信息和功能；只有用户明确要求时才删除或替换。
3. 优化信息层级、布局、间距和字体，让姓名、介绍、项目和联系方式容易找到。
4. 保证文字和按钮清晰可读，检查窄屏下是否溢出或遮挡。
5. 避免无意义的复杂动画；沿用 Workshop 的单文件 `index.html`，保持实现简单。
6. 保证基础交互正常，例如深浅色切换按钮可以反复点击。
7. 修改后重新预览，核对用户需求、原有内容和交互；发现问题后修复并再次检查。无法验证的部分应说明。
